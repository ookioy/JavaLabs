ЛР 5: Сортування об’єктів та Comparator/Comparable

Мета: Навчитися сортувати колекції об’єктів у Java за різними критеріями з використанням Comparable, Comparator та лямбда-виразів.

Завдання:

    Для кожного класу реалізувати:
    інтерфейс Comparable<T> для основного поля;
    додаткові Comparator для альтернативних критеріїв.


У класі GenericRepository<T> реалізувати метод sortByIdentity(String order).
Для кожної сутності створити специфічні репозиторії (StudentRepository, GroupRepository), в яких створити методи сортування за різними критеріями. 
Використати лямбда-вирази для створення Comparator або посилання на методи (method reference).
Додати логування виконаних операцій.
Написати юніт-тести для перевірки правильності сортування.


Main:

    створює об’єкти та додає їх до репозиторію;
    виконує сортування за різними критеріями;

демонструє результати роботи з логуванням.
