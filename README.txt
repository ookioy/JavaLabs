ЛР 6: Stream API

Мета: Навчитися застосовувати Stream API для пошуку та фільтрації об’єктів у колекціях, створювати конкретні репозиторії для кожної сутності з індивідуальними методами пошуку.

Завдання:
Використати створені раніше репозиторії для кожної сутності предметної області, який розширює базовий репозиторій.
У спеціалізованих репозиторіях реалізувати методи пошуку за специфічними полями (наприклад: пошук за назвою, діапазоном значень).
Реалізувати ці методи за допомогою Stream API (filter, map, flatMap).
Додати приклади використання термінальних операцій: collect, forEach, reduce.
Додати логування викликів методів пошуку.
Написати юніт-тести для перевірки коректності роботи методів спеціалізованих репозиторіїв.

Main:
створює кілька сутностей і додає їх до відповідних репозиторіїв;
виконує пошук за різними критеріями через методи спеціалізованих репозиторіїв;
демонструє використання Stream API та роботу з результатами пошуку;
порівнює продуктивність звичайного та паралельного стріму (stream vs parallelStream).
