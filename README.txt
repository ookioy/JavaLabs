ЛР 3: Обробка виключень

Мета: Навчитися обробляти виключення в Java, реалізувати власний клас виключень, працювати з файлами та рядками, а також логувати події програми.
Завдання:
Створити власний клас виключень InvalidDataException для обробки некоректних даних.
Дані для  незалежних класів (без агрегації) зчитувати з файлу. Формат файлу – довільний (наприклад, CSV або текстові рядки).
Реалізувати обробку виключень для:

    некоректних даних при зчитуванні з файлу;
    потенційних помилок при роботі з файлами (FileNotFoundException, IOException);
    будь-яких інших логічних помилок у класах.

Використати блоки try-catch-finally та, за потреби, multi-catch.
Додати логування усіх критичних та інформаційних подій програми (створення об’єктів, обробка виключень, успішне завершення операцій).
Написати базові тести для перевірки:

    коректного створення об’єктів,
    обробки некоректних даних (InvalidDataException),
    правильності логіки методів класів.

Створити демонстраційний клас Main, який:

    зчитує дані з файлу;
    створює об’єкти  класів;
    обробляє можливі помилки через власні та стандартні виключення;
    демонструє роботу логування.
